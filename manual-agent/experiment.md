# Експеримент: one-shot vs власний агент vs ADK-агент

Предметна область: життєвий цикл MonoBehaviour (Unity).
Модель: gemini-3.6-flash (усі три системи).

## Запити

| № | Тип | Запит | Очікувана траєкторія |
|---|-----|-------|----------------------|
| 1 | A | Розкажи про функцію FixedUpdate | lookup → finish |
| 2 | B | Порівняй Awake і Start | lookup × 2 → finish |
| 3 | C | Порівняй Awake, OnEnable і Start | lookup × 3 → finish |
| 4 | D | Опиши функцію OnApplicationQuit | lookup → NOT_FOUND → finish із визнанням відсутності даних |
| 5 | E | Що таке життєвий цикл MonoBehaviour в Unity? | finish одразу |

Примітка до запиту 4: OnApplicationQuit існує в Unity, але її немає в середовищі. Це
саме той випадок, коли one-shot відповість із загальних знань без перевірених даних.

## Як запускати

```bash
# one-shot
uv run python main.py "<запит>" --mode oneshot
# власний агент (трасування збережеться в traces/)
uv run python main.py "<запит>"
# ADK-агент (з каталогу adk-agent)
agents-cli run "<запит>"
```

Для ADK кількість викликів LLM і дій дивись у панелі подій Playground, час вимірюй секундоміром.
Між запусками роби паузу (ліміти безкоштовного рівня, помилка 429).

## Підсумкові значення для паспорта агента

- Правильність (середнє, 0–2): one-shot … / власний … / ADK …
- Галюцинації на запиті D: one-shot … / власний … / ADK …
- Середня кількість викликів LLM: one-shot 1 / власний … / ADK …
- Середній час, с: one-shot … / власний … / ADK …

## Еталон правильності (за environment.py)

Оцінюй відповідь за текстом об'єктів у `agent/environment.py`: 2 — усі ключові факти
об'єктів передано правильно; 1 — частково; 0 — хибно.
Для D правильна відповідь: визнання, що перевірених даних немає.
